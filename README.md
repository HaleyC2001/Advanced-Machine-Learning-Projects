# Advanced Machine Learning Projects

A collection of advanced machine learning projects and learning exercises implemented in Python, covering deep learning, computer vision, and applied classification tasks.

---

## Projects

### 🌍 World Happiness Classification Competition
**`World_Happiness_Classification_Competition.ipynb`**

A classification project using the World Happiness dataset to predict happiness categories across countries. Techniques include:
- Random Forest classification
- Deep learning models
- Model evaluation and comparison

---

## Learning Exercises

### 🧠 Neural Networks with Keras
**`1-Neural Network with Keras.ipynb`**

An introduction to building neural networks using Keras, covering:
- Implementing a sequential model
- Adding dense layers and activation functions
- Analyzing a model's architecture and summary output

---

### 🖼️ CNN for Image Classification
**`2_CNN_Image_classification.ipynb`**

A Convolutional Neural Network built to classify flower images, covering:
- Dataset preprocessing and exploration
- Building and training a CNN model
- Evaluating model performance

---

## Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Key Libraries:** TensorFlow/Keras, scikit-learn, NumPy, pandas, matplotlib
